# 準1級 合格デスク

英検準1級の対策アプリです。スマホのブラウザで動き、ホーム画面に追加してアプリのように使えます。

- 苦手語クイズ（間隔反復）: パス単でわからなかった単語をメモして、4択・赤シート・つづりで復習
- TODOと学習記録: 試験日から逆算した週間プラン、ストップウォッチ、技能別グラフ
- 過去問スコア: 大問別に記録して弱点を表示
- 英作文: 要約・意見論述の語数カウンター、タイマー、自己採点
- バックアップ: JSONファイルで保存・読み込み（別の端末への引っ越し、claude.ai版との行き来）

**アプリのアドレス: https://hanadamushin.github.io/eiken/**

## フォルダの中身

| ファイル | 内容 |
|---|---|
| `eiken-pre1-desk.html` | アプリ本体（claude.ai に公開している版） |
| `build_pages.py` | 本体から GitHub Pages 用のファイルを作るスクリプト |
| `docs/` | GitHub Pages で公開されるファイル一式（`index.html`・アイコン・`manifest.webmanifest`・`sw.js`） |

## GitHub Pages の設定

リポジトリ `hanadamushin/eiken` の **Settings → Pages** で、Source を「Deploy from a branch」、Branch を `main` / `/docs` にしています。`main` に push すると、1〜2分で上のアドレスに反映されます。

リポジトリは Public なので、アプリのコードは誰でも見られます。**学習記録はそれぞれのブラウザの中に保存され、GitHub には送られません。**

## スマホのホーム画面に追加する

- iPhone（Safari）: 共有ボタン →「ホーム画面に追加」
- Android（Chrome）: メニュー →「ホーム画面に追加」または「アプリをインストール」

ホーム画面から開くと、アドレスバーのない全画面で使えます。一度開いたあとは、電波がなくても起動できます。

## 記録の保存と別の端末への引っ越し

GitHub Pages 版の記録は、そのブラウザの中だけに保存されます。端末どうしで自動では同期しません。

- **バックアップ**: アプリの「その他 → データの保存・引っ越し → バックアップを保存」で JSON ファイルを保存します。スマホでは共有シートが開くので、「ファイルに保存」や Google ドライブ、LINE の Keep などに送ります。7日以上保存していないと、ホームにお知らせが出ます。
- **別の端末へ移す**: 別の端末で「バックアップを読み込む」→「統合する」。
  - 統合: 今の端末の記録を残したまま、バックアップにしかない記録を足します。同じ単語はクイズ回数の多い方を残します。
  - 置き換え: 今の端末の記録を消して、バックアップの内容だけにします。
  - 統合では、片方の端末で消した記録は消えずに残ります。消したものを反映したいときは「置き換え」を使います。
- **ファイルを扱いにくいとき**: 「テキストでコピー / 貼り付け」で、テキストとしてコピーし、メモアプリなどで送って貼り付けることもできます。
- **claude.ai 版との行き来**: どちらの版も同じ形式の JSON なので、そのまま読み込めます。

iPhone の Safari は、しばらく開かないサイトのデータを消すことがあります。ホーム画面に追加して使い、定期的にバックアップを保存してください。

## アプリを直したとき

`eiken-pre1-desk.html` を直したら、`docs/` を作り直して push します。

```bash
python build_pages.py
git add -A
git commit -m "アプリを更新"
git push
```

PNG アイコンの作成に Pillow を使います（`pip install pillow`）。ない場合は SVG アイコンだけで作ります。
